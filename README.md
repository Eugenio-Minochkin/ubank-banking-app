# ubank personal copies

Based on https://github.com/Yanivro/ubank-banking-app (adc80c7).

- Evgenii Minochkin: evgenii/index.html
- Mariia Sokolova: mariia/index.html

Open index.html through a static web server to select a profile, or open either profile HTML file directly.
Transaction dates are shifted forward by 111 days, ending on 28 September 2026. Original intervals, amounts, balances, and app behavior are preserved. Each copy retains both original bank accounts.

This is a personalized static demo with inherited sample financial data, not a connection to a bank or an official bank document.
